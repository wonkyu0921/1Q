# 견적서 자동 작성 (PULSE531)

`견적서.html` 을 브라우저(크롬/엣지/사파리)로 열면 바로 사용할 수 있습니다. 설치 필요 없음.

- 거래처·품목·단가·수량 입력 → 공급가액, 세액(10%), 합계, **한글 금액(육백오십사만오천 원)** 자동 계산
- 견적번호 자동 생성: `날짜 + 일련번호` (예: 20261126001, 같은 날 저장한 견적이 있으면 002, 003…)
- **PDF 저장 / PNG 이미지 저장 / 인쇄** (PNG는 카톡 전송용)
- 견적 저장 목록: 열기 · 복사(새 번호로) · 삭제, JSON 백업/불러오기
- 공급자 정보, 로고, 도장 이미지, 최소 표 줄 수, 세율 설정 (자동 저장)
- 비고는 한 줄에 하나씩, 번호 자동. 줄 앞에 `*` 를 붙이면 빨간 글씨

## 수정하려면
`src/estimate.html` 을 고친 뒤 `python3 build.py` 를 실행하면 `견적서.html` 이 다시 만들어집니다.
